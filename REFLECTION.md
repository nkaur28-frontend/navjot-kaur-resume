# Reflection - Resume Website Assiignment 

## Overview
In this assignment I created a personal resume website using HTML. The goal was to properly structure the content and apply semantic HTML elements.

## What I Learned
I learned how to:
- Use semantic HTML elements like header, main, section, and footer
- Add images and SVG graphics
- Improve accessibility using alt.
- Use Git and GitHub 

## Conclusion
This project helped me understand how to build a structured and accessible webpage. It also improved my confidence in using GitHub and writing clean HTML code.
